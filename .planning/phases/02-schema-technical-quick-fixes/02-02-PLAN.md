<objective>
Apply three technical/performance fixes for Phase 2:
- Add preload="none" to both video elements — Hero.jsx (background autoplay) and VideoSection.jsx
  (user-controlled player) — so browsers do not prefetch video bytes on initial page load (PERF-05)
- Refactor Gallery.jsx to move shuffle from useMemo (runs on server during SSR) to useEffect
  (runs client-side after hydration), eliminating the hydration-order mismatch that causes CLS (PERF-06)
- Create public/favicon.png by resizing the existing logo-black.png (10000x10000 RGBA PNG) to 64x64
  using the macOS sips tool, then declare it in index.html via <link rel="icon"> (PERF-07)

Purpose: These fixes address measurable performance regressions — video preload wastes bandwidth,
gallery CLS degrades CLS score, missing favicon triggers a browser console error on every page load.
All changes are additive (one prop per video, hook swap in Gallery, one file + one HTML tag for favicon).

Output: Three modified JSX components, one new PNG, and one new <link> tag in index.html.
</objective>
